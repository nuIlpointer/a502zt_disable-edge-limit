# ZTE nubia Fold Edge Limit Suppressor (`a502zt_disable-edge-limit`)

ZTE nubia Fold（A502ZT / Z9900S）向けの **画面端タッチ感度改善・パームリジェクション抑制モジュール**（KernelSU / APatch / Magisk 対応）です。

---

## 📌 概要

nubia Fold を折りたたんだ状態（カバーディスプレイ使用時）や展開時に、**画面の左右端（エッジ部分）のタップ判定が極端に鈍くなったり、無反応エリア（不感帯）になってしまう問題**を解消します。

### 解決される症状
* 画面端にあるキーボードの文字（「1」「0」「Q」「P」「a」など）が反応しづらい
* 画面端のスワイプ（戻るジェスチャー）の初動が弾かれる
* 画面端付近のアプリアイコンやボタンがタップしにくい

---

## ⚙️ 仕組みとチューニング内容

nubia Fold の Linux カーネルには `/proc/touchscreen/edge_report_limit` というタッチスクリーンドライバのパームリジェクション（誤タッチ防止）制御ノードが存在します。

純正状態では、端の数ピクセルに対するタップや長押しを抑制するアルゴリズム（`algo_open: 1`）が強制的に有効化されています。本モジュールはこれを解除し、感度を通常領域と同等に開放します。

### 適用されるパラメータ
| パラメータ | 純正値 | 本モジュール設定値 | 説明 |
| :--- | :--- | :--- | :--- |
| **`algo_open`** | `1` (有効) | **`0` (無効)** | エッジ抑制アルゴリズムを完全無効化 |
| **`click_pixel`** | `10` | **`4`** | タップ有効判定のピクセル閾値を緩和 |
| **`long_press_open`**| `1` (有効) | **`0` (無効)** | 端部での長押し抑制を無効化 |
| **`long_press_pixel`**| `10,10,20,20` | **`4,4,4,4`** | 長押し判定領域のピクセル制限を緩和 |
| **`jitter_pixel`** | `10` | **`5`** | 端部の手ブレ・微小移動判定を緩和 |

### 🔄 開閉検知・自動再適用デーモン搭載
nubia Fold は**端末の開閉（折りたたみ ⇄ 展開）が行われると、タッチドライバによって設定値が純正値にリセットされる**仕様を持っています。  
本モジュールはバックグラウンドデーモンが常駐し、`/proc/touchscreen/fold_state` の状態変化を監視して、**開閉後も即座に感度改善設定を自動で再適用**します。

## 📱 対応環境

* **対象端末**: ZTE nubia Fold (A502ZT / Z9900S)
* **対応 OS**: Android 15 (Linux Kernel 6.6)
* **Root 環境**:
  * KernelSU / KernelSU-Next
  * APatch
  * Magisk (v24.0 以降)

---

## 📥 インストール方法

1. 本リポジトリの [Releases](https://github.com/nuIlpointer/a502zt_disable-edge-limit/releases) から最新の `a502zt_disable-edge-limit-vX.X.X.zip` をダウンロードします。
2. お使いの Root マネージャーアプリ（KernelSU / APatch / Magisk）を開きます。
3. **「モジュール」** タブへ移動し、**「ストレージからインストール」** を選択します。
4. ダウンロードした `.zip` を選択してインストールします。
5. 端末を再起動（または KernelSU の場合は「アクション」ボタンを実行）します。

---

## 🔍 動作確認方法

Termux または PC の ADB Shell（Root権限）で以下のコマンドを実行します：

```bash
su -c "cat /proc/touchscreen/edge_report_limit"
```

出力結果の末尾が以下のようになっていれば正常に動作しています：

```text
algo_open:    0
jitter_pixel:    5
click_pixel:    4
long_press_open:    0
long_press_pixel:    4    4    4    4
```
